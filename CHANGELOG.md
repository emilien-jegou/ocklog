## [0.0.2] - 2026-09-26

First release of the project with:
* ⚡ Logs all your local containers with automatic stream re-attachment across crash-loops.
* ⏱️ Compose style logs viewing (merged timeline).
* 🔍 Log filtering using our custom query language and view changes as you type.
* ⌨️ **Vim Navigation** vim style navigation and clipboard support
* 📦 **Services Switcher** turn services on/off without leaving the ui.
* 🎨 Themed derived from terminal ANSI colors

Also:
- Restart, stop, kill containers directly from service menu.
